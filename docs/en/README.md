# Smart CI/CD

> Source pair:
> - English: ./README.md
> - 中文: ../zh-CN/README.md

Smart CI/CD is a Kubernetes-native agentic build platform. It defines build workflows from natural language, orchestrates runners on Kubernetes, executes builds and tests with Docker / BuildKit, and uses AI for runtime supervision, controlled interventions, release preparation, PR review, and next-module planning.
