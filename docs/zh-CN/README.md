# Smart CI/CD

> 对应文档：
> - 中文：./README.md
> - English: ../en/README.md

Smart CI/CD 是一个 Kubernetes-native 的 agentic build platform。  
它通过自然语言定义构建流程，在 Kubernetes 上编排 runner，调用 Docker / BuildKit 执行构建与测试，并结合 AI 完成运行时监控、受控干预、release 准备、PR 审查与下一模块规划。
