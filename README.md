# Smart CI/CD

- [English](./docs/en/README.md)
- [简体中文](./docs/zh-CN/README.md)

A Kubernetes-native agentic build platform for natural-language pipeline definition, runner orchestration, runtime supervision, controlled intervention, release preparation, and PR automation.

## Documentation Structure

```text
docs/
├── en/          # English docs
├── zh-CN/       # Simplified Chinese docs
└── shared/      # Language-neutral shared docs and source-of-truth artifacts
```

## Recommended Rule

- Keep product and design docs in both `docs/en/` and `docs/zh-CN/`
- Keep schemas, diagrams source, ADR indexes, and language-neutral references in `docs/shared/`
- Prefer one doc path per topic, mirrored across languages
